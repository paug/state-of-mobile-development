# 2027 State of Mobile Development

As the industry is changing fast, we're aiming to run a survey about the state of mobile development, like there already exist for other communities.

The survey is currently in **brainstorming phase**, collecting feedback and questions from the community.

If there is a question you want to see, please [open a pull request](https://github.com/paug/state-of-mobile-development/edit/main/questions.md) to update [questions.md](questions.md).
